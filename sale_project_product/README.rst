======================================
Customização para criar projeto ou tarefa a partir do pedido de venda
======================================


Este módulo permite criar tarefas em um projeto existente a partir do pedido de venda, configurando o produto com o projeto onde a tarefa deve ser criada.

**Table of contents**

.. contents::
   :local:

Installation
============

Este módulo depende do módulo sale_project_copy_tasks

Configuration
=============


Usage
=====
    1. Configurar o produto, marcando a opção "Criar Projeto" ou "Criar Tarefa";
    2. Criar um Pedido de Venda, e incluir o produto configurado;
    3. Validar o Pedido de Venda;
    4. O Projeto ou a Tarefa será criado automaticamente, e vinculado ao Pedido de Venda;
